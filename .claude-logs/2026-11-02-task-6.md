# Task 6: per-user evidence model and synthetic question-ranker experiment

## Prompt (summary)

Implement Task 6 of the v2 learning-loop plan on `feature/v2-model`: whole-meal `buildEvidence` with Beta(1,1) smoothing and a dish candidate that needs repeat exposure plus comparison meals; `rankQuestions` and `scoreIntents` over the approved intents `symptom_detail` and `pre_existing`; an owner-scoped `listObservations` in the feel repository; a seeded synthetic generator and a logistic-regression trainer that writes a deterministic `question-weights.ts`, compares it with a fixed baseline on held-out seeds, and records that synthetic data has no clinical validity. Use TDD, keep it minimal, and do not wire the ranker into the API.

## Result

- Added `question-model.ts`, the generated `question-weights.ts`, `scripts/synthetic-question-data.ts`, `scripts/train-question-ranker.ts`, `npm run train:questions -w backend`, and `listObservations(userId)`. It counts confirmed dishes only, keeps the owner's rows only and drops check-ins made more than 24 h after the meal.
- Held-out accuracy on 500 synthetic users (seeds 100001-100500): the fixed baseline scored 0.664 and the trained ranker 0.782. `useTrainedRanker` is therefore true. This measures question selection on simulated data only. It has no clinical validity.
- Two training runs produced byte-identical weights (sha256 d8efbf5e…56f1).
- `npm test`, `npm run lint` and `npm run build` pass. The opt-in local PostgREST integration test also passes.
