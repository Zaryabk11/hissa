A Git worktree itself does **not** get pushed to GitHub. It’s just another local working directory linked to your repository.

When you push a branch, GitHub receives the branch’s **commits**—including its commit history. Uncommitted changes in that worktree are not included; commit them first. For example:

```bash
git push -u origin integration/v2-all
```

That pushes the branch and its commits, regardless of which worktree you run it from.
